Missed targets and mitigation

F4 tag precision (planted reference) · missed: 76% against >= 80% (n = 30, 95% CI 69–83%)

tp 95 / fp 30 / fn 31 over 125 predicted tags; CI resamples the 30 stories

Diagnosis (added 2026-11-14 after results; reviewer judgement, not a registered measure): every false positive sits on a did-box unit that overlaps a supported or partial planted claim. About 23 of 30 are skills the unit text does state but the 2–3-skill archetype reference omits (for example Python, data analysis), so precision against the planted reference is a lower bound. The remaining ~7 are over-broad or wrong tags, for example ICT system integration (×3) on work that only uses a system as a data source. Mitigation: proposed extraction amendment (ESCO scope notes in the prompt's skill list; a system only named as a data source is not evidence of integrating it), pending approval and a full disclosed re-run. Threshold unchanged.

Consensus labels exclude adjacency by design (method.md §1). Adjacency can only raise the engine tier, never lower it, so where the judge matches consensus (6 of the 7 disagreements) every adjacent path puts the engine above consensus; this target partly measures that design choice. Mitigation: proposed adjacency amendment (no same-skill adjacency on hub skills tagged across many outcomes; an adjacent path alone cannot lift a pair from none to worth), pending approval and a full disclosed re-run. Threshold unchanged.
